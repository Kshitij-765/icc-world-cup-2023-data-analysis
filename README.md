# ICC Cricket World Cup 2023 — Data Analysis

## Overview

A data analysis project based on match-level data from all 48 matches of the ICC Cricket World Cup 2023.

## Objective

The project analyses various match statistics including:

- Match scores
- Boundaries
- Extras
- Toss outcomes
- Match winners
- Match-level statistics

## Data Cleaning

The dataset was cleaned using Pandas, including handling missing values, removing unnecessary columns and checking for duplicate records.

## Analysis

The project uses Python, Pandas to answer a series of cricket-related analytical questions and derive insights from the match data.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Project Structure

- `ICC_World_Cup_2023_Analysis.ipynb` — Complete analysis notebook
- `README.md` — Project documentation

(Attached in the repository)
Match-level data covering all 48 matches of the ICC Cricket World Cup 2023.
